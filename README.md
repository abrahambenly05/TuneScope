# TuneScope

Music discovery platform: cari lagu, artis, dan album, simpan favorit, buat playlist, dan tulis review.

## Tech Stack
React + TypeScript, Tailwind CSS, FastAPI, PostgreSQL, SQLAlchemy, JWT, pytest, Vitest

## Struktur
- `frontend/` : aplikasi React
- `backend/` : REST API FastAPI
- `docs/` : ERD, keputusan arsitektur, desain

## Roadmap
- [ ] Phase 1: MVP (Home, Search, detail pages)
- [ ] Phase 2: Full stack (auth, favorites, playlist, profile)
- [ ] Phase 3: Social (reviews, rating, public playlist)
- [ ] Phase 4: Advanced (recommendation)
